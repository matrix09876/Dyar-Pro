# 📋 تقرير ترقية Dyar Ultra UI — ما نُقل من Dyar Pro V10

**التاريخ**: 13/06/2026 · **الاتجاه**: Pro V10 → Ultra UI (جعل Ultra نسخة
سوبر-سِت كاملة معتمدة).

## 1) تحليل الفجوات (ماذا كان ينقص Ultra UI فعلًا)

بعد فحص كل صفحات Ultra UI الـ35، تبيّن أنه **أغنى مما يبدو**: عنده
بالفعل صفحات Marketplace · Services · Taxi · Parcel · **Seller (تاجر)**
· **B2B & Community** · Auth & Account · حالات (States) · نظام تصميم
وأيقونات وi18n وQA وبروتوتايب. لذلك الفجوات الحقيقية مقابل Pro V10
انحصرت في **ثلاثة أقسام كبرى غائبة تمامًا**:

| الفجوة | الحالة في Ultra قبل | المصدر في Pro V10 |
|---|---|---|
| **لوحة تحكم الإدارة** | ❌ معدومة كليًا | صفحة `16:3` — A1–A24 |
| **تطبيق السائق/المندوب** | ❌ لا يوجد (Seller=تاجر، Parcel=زبون) | صفحة `11:2` — D1–D11 |
| **نظام هبوط الفئات السوبر-آب** | ❌ (Services موجود لكن بلا قرب-مني/قوالب فئات) | صفحة `54:2` — C1–C8 |

بنود أصغر (تُضاف ضمن ما سبق أو لاحقًا):
- تصحيح الموقع (الجليل/+972 بدل رام الله/+970) على شاشات Ultra الأصلية.
- ✓ على شريط تقدّم الطلب (إصلاح إتاحة — لون فقط حاليًا).
- نقاط دخول المساعدة الصوتية «تاليا».

## 2) ما يُبنى الآن داخل Ultra UI (3 صفحات جديدة)

### 🖥️ Admin Dashboard (جديدة — 24 شاشة)
نظرة عامة، طلبات بخط زمني، مشاوير، طرود، حجوزات، متاجر، سائقون
(+جوائز)، مستخدمون (+B2B +نقاط)، تسويق (Hub)، مالية، **تقارير**،
بانرات، وظائف، دعم (عدّادات حية)، مدن (+تفعيل فئة جماعي)، إعدادات
المدينة، ملاحظات (كانبان)، تدريب، سجلات (security)، فريق (+دور خدمة
العملاء)، **بث الإشعارات**، **العناوين المحظورة**، إعدادات — كلها
بهيدر ثلاثي اللغة وقائمة جانبية يمنى.

### 🛵 Driver App (جديدة — 11 شاشة)
دخول OTP، تسجيل KYC (مركبة/رخصة/لوحة)، مركز المهام (تبديل أونلاين +
تعرفة ديناميكية + شرائح 🍔/📦/🚕 + نصيب السائق الأخضر)، مهمة نشطة،
طرد نشط (OTP 4 خانات)، مشوار نشط (هيرو داكن)، الأرباح (سحب فوري)،
السجل، الدعم AI، الملف والوثائق، قفل Face ID.

### 🧩 Super-App Categories (جديدة — ~12 شاشة)
قالب هبوط الفئة + 3 تنويعات (ملابس/إلكترونيات/B2B)، تدفّق
صالون-قرب-مني الثلاثي (مسافة + أقرب موعد + حجز)، استشارة (📞/🏢)،
متجر ملابس بمقاسات، إلكترونيات بمواصفات+ضمان، كتالوج جملة B2B
(حد أدنى+عرض سعر+ائتمان)، مكتبة المهن الـ14، مكتبة MenuBrand الخمس.

## 3) ملاحظة استراتيجية (مهمة)
**Pro V10 يبقى النسخة المربوطة بالكود الإنتاجي** (Firebase حي، 34 دالة
منشورة، اللوحة تعمل). نقل هذه الأقسام إلى Ultra UI يجعله **مرجع تصميم
سوبر-سِت كامل** للاعتماد البصري كما طلبت — لكن عند بناء الكود يبقى
Pro V10 هو مصدر الحقيقة. الأفضل اعتبار Ultra UI «مكتبة التصميم المرجعية
الكاملة» وPro V10 «نسخة الإنتاج».
